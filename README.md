# 🚆 Kereta Manager Indonesia

**Kereta Manager Indonesia** adalah game simulasi manajemen perusahaan kereta api berbasis web (*browser-based tycoon game*). Pemain berperan sebagai direktur perusahaan kereta api yang bertugas mengelola armada lokomotif, rute perjalanan antar kota di Pulau Jawa dan Sumatra, keuangan, hingga menghadapi dinamika cuaca dan event musiman seperti Mudik Lebaran.

---

## ✨ Fitur Utama
- **Manajemen Armada & Dipo**: Beli dan rawat berbagai jenis lokomotif legendaris (CC201, CC203, CC206) serta gerbong penumpang.
- **Peta Rute Multi-Region**: Jelajahi jalur kereta api interaktif di Lintas Jawa dan Lintas Sumatra.
- **Sistem Keuangan & Grafik**: Pantau tren pendapatan dan pengeluaran harian secara *real-time* menggunakan Chart.js.
- **Dinamika Cuaca & Event**: Hadapi tantangan cuaca ekstrem dan lonjakan penumpang musiman (Mudik).
- **Layanan Perbankan & Kredit**: Amankan arus kas perusahaan dengan fasilitas pinjaman bank ber-bunga harian.
- **Sistem Pencapaian (Achievements)**: Raih berbagai badge dan hadiah eksklusif.
- **Mode Tampilan**: Dilengkapi opsi *Dark/Light Mode* yang nyaman untuk mata.

---

## 🛠️ Teknologi yang Digunakan
- **HTML5 & CSS3** (Modern Dashboard UI)
- **Vanilla JavaScript (ES6+)**
- **HTML5 Canvas API** (Animasi Peta Perjalanan)
- **Web Audio API** (Efek suara interaktif tanpa file audio eksternal)
- **Chart.js** (Analitik laporan keuangan)

---

## 🎮 Cara Bermain
1. Buka link game melalui [GitHub Pages](https://fastxgaming.github.io/Kereta-Manager-ID/)) .
2. Beli lokomotif pertama Anda di menu **Dipo Kereta**.
3. Pilih rute perjalanan dan tetapkan jadwal serta tarif tiket.
4. Perhatikan kondisi keuangan, bayar pinjaman bank jika ada, dan kembangkan perusahaan kereta api terbesar di Indonesia!
